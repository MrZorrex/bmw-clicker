# Как запустить игру на ПК

Игра «Перекуп BMW» — обычный многофайловый пакет: `index.html` + один
JS-файл + картинки (`.jpg`) рядом. Всё работает офлайн, без установки.

## Вариант 1. Готовая сборка (проще всего)

1. Скачайте архив `publish/bmw-clicker-yandex.zip` из ветки
   `arena/01a08cbd-bmw-clicker`.
2. Распакуйте архив в любую папку (получится `index.html` + папки
   `assets/`, `models/`, `cards/`, `rewards/`).
3. Откройте `index.html` двойным кликом — игра запустится в браузере.

Контроль: 1 302 025 байт, SHA-256 `69d710c4…50aca7`.

> Вне платформы Яндекс Игр SDK недоступен — игра честно показывает
> заглушку «Откройте игру в Яндекс Играх» (так задумано: это проверка
> наличия платформы, а не ошибка). Полная игра — после загрузки архива
> в Консоль разработчика (см. `PUBLISH.md`).

## Вариант 2. Режим разработчика (с живым кодом)

Нужен Node.js 18+. В папке проекта:

```bash
npm install
npm run dev
```

Открыть http://localhost:5173/ — страница сама перенаправит на игру.

## Как пересобрать пакет

```bash
npm run build          # только папка dist/ (35 файлов)
npm run build:yandex   # dist/ + 34 проверки + архив publish/*.zip + 5 проверок архива
```

Проверки (`scripts/validate-yandex.mjs`) ловят все известные причины
отказов Консоли заранее: SDK, следы сервисного хранилища, внешние
ссылки, структуру архива. Зелёная сборка = можно загружать.

## Частые вопросы

**Белый экран / заглушка «Откройте игру в Яндекс Играх»?**
Это нормально вне платформы: игра требует SDK Яндекса и не притворяется,
что работает. Загрузите архив в Консоль — там всё заведётся.

**Можно ли открыть одиночный `index.html` без остальных файлов?**
Нет: картинки и код игры — отдельные файлы рядом, одиночный HTML без них
не имеет смысла. Всегда держите распакованную папку целиком.

**Что за `dev.html`?**
Шаблон входа для разработки (с HMR). В готовом пакете его нет —
там только собранный `index.html`.
