# Как запустить игру

## Вариант 1 — просто играть (без установки чего-либо)

1. Возьми файл **`index.html`** в корне репозитория (это вся игра в одном файле, ~2 МБ).
2. Открой его **двойным кликом** в любом современном браузере (Chrome, Edge, Firefox)
   — или положи на любой хостинг.
3. Всё — сервер, интернет и Node.js **не нужны**.

Прогресс сохраняется автоматически в браузере (localStorage), так что не открывай
каждый раз новую копию файла из загрузок — играй из одного и того же места.

Язык (русский/английский) переключается иконкой глобуса в шапке игры — в меню
подписано «РУС Русский» / «ENG English». На ПК кликать можно Пробелом. Игра
подстраивается под портретную и альбомную ориентацию.

Этот же `index.html` подходит и для **Яндекс Игр**: SDK платформы в него встроен
(тег `/sdk.js`, `YaGames.init()`, Loading/Gameplay API, автоопределение языка).
Для загрузки в Консоль используй архив `publish/bmw-clicker-yandex.zip` из команды
`npm run build:yandex` — там `index.html` уже лежит в корне архива.

## Вариант 2 — разработка / изменение кода

```bash
npm ci          # один раз: установка зависимостей
npm run dev     # запуск для разработки → http://localhost:5173
```

Дев-сервер открывает шаблон `dev.html` (живой код из `src/` с HMR). Готовый
собранный файл — корневой `index.html` — при разработке не трогается.

## Как пересобрать `index.html` после изменений в коде

```bash
npm run build
```

Команда собирает игру в `dist/index.html` и кладёт готовый файл в корень —
**`index.html`** (один файл, со встроенным SDK). Двойной клик по нему запускает
игру офлайн; внутри iframe Яндекс Игр тот же файл работает с полным SDK
платформы (вне платформы SDK не дёргается и не задерживает старт).

> Для публикации в Яндекс Играх: `npm run build:yandex` — сборка + проверка
> пакета + архив `publish/bmw-clicker-yandex.zip` для Консоли.
