# Публикация в Яндекс Играх

## Сборка

```bash
npm ci
npm run pack
```

Готовый архив появится в `publish/bmw-clicker.zip`. В него входят `dist/` и все локальные ассеты игры. Для локальной проверки: `npm run dev`.

## Кабинет разработчика

1. Создайте игру в [Консоли разработчика Яндекс Игр](https://yandex.ru/dev/games/).
2. Загрузите `publish/bmw-clicker.zip` как HTML5-игру.
3. В настройках рекламы включите межстраничную и rewarded-рекламу. Игра вызывает их только через `ysdk.adv`.
4. Для прогресса включён `getPlayer().setData/getData`; гостевой режим автоматически использует локальное хранилище.
5. Для IAP добавьте товары в кабинете. Клиентская обвязка использует `getPayments({ signed: true })`, `purchase` и `consumePurchase`; выдачу товара необходимо подтверждать на сервере согласно правилам Яндекс Игр.
6. Проверьте LoadingAPI, GameplayAPI, паузу `game_api_pause`/`game_api_resume`, звук, рекламу и покупки в тестовом режиме.

Игра не зависит от `localhost` и работает офлайн вне Яндекс Игр с безопасными no-op fallback для SDK.
